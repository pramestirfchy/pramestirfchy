I'm Pramesti Refita Cahyani, an Information Systems student at Universitas Bina Sarana Informatika with a strong interest in back-end development, UI/UX design, and data analysis. I enjoy building systems that solve real problems and picking up new tools whenever a project needs them.

So far I've worked on Savora Paradise, a sales dashboard with real-time analytics and a weather-based menu recommendation system; SiPPPA, a Laravel-based platform for reporting cases of violence with an integrated AI chat service; and a Payroll System covering recruitment, employee records, attendance, leave management, and payroll processing.

In addition to these highlighted projects, I have also developed 80+ academic, personal, and collaborative projects across web development, information systems, business applications, and UI/UX design. Many of these projects are still being documented and refined, so not all of them are presented in detail here yet.
